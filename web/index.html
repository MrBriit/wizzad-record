Check a Wizzad record

Every Wizzad record is signed, and the key that checks the signature is published. This page checks it in your browser — nothing is sent anywhere, and none of Wizzad's code is involved. Read what a record is before you rely on one.

3 · An Open Badges credential

A task's credential carries a Data Integrity proof (eddsa-rdfc-2022), which needs RDF canonicalisation to check. That is a larger library than belongs in one page, so check credentials with the command line: npx wizzad-record credential credential.json --keys did.json.
